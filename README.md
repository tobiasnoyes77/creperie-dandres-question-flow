# Question Flow and Answers — Crêperie D'Andres 12

A small static site presenting ten curiosity questions asked in Spanish between
`47:04` and `48:30` of the *Crêperie D'Andres 12* recording, with English
translations, researched answers, a transcript excerpt, and references.

## Files

- `index.html` — the page
- `styles.css` — styling (light and dark, responsive, print-friendly)
- `creperie-dandres-question-flow.md` — the source notes the page was built from

## Not published

The source audio (`.m4a`) and the raw Whisper transcript artifacts
(`transcripts/` — `.txt`, `.json`, `.srt`, `.vtt`, `.tsv`) are kept locally and
are excluded from this repository via `.gitignore`.

## Local preview

```sh
python3 -m http.server 8000
# then open http://localhost:8000
```
